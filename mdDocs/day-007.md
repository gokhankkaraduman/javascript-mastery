# 🚀 Day 7 of 365: Objects - Complex Data Structures

Today's journey introduces **Objects** - one of the most fundamental and powerful data structures in JavaScript. Objects allow you to store related data and functionality together using **key-value pairs**.

---

## 1. What is an Object?

An **object** is a collection of **key-value pairs** (also called **properties**). Think of it as a container that holds related information.

### Real-World Analogy:
Imagine a person:
- Name: "John"
- Age: 25
- City: "New York"

In JavaScript, this becomes:
```javascript
let person = {
    name: "John",
    age: 25,
    city: "New York"
};
```

## 2. Creating Objects

### A. Object Literal (Most Common)
```javascript
// Empty object
let emptyObj = {};

// Object with properties
let car = {
    brand: "Toyota",
    model: "Camry",
    year: 2022,
    color: "blue"
};

// Object with different data types
let student = {
    name: "Alice",           // string
    age: 20,                 // number
    isActive: true,          // boolean
    grades: [85, 90, 92],    // array
    address: {               // nested object
        city: "Boston",
        zipCode: "02101"
    }
};
```

### B. Using `new Object()` (Less Common)
```javascript
let person = new Object();
person.name = "John";
person.age = 30;

console.log(person);  // {name: "John", age: 30}
```

## 3. Accessing Object Properties

There are **two ways** to access object properties:

### A. Dot Notation (Most Common)
```javascript
let person = {
    name: "John",
    age: 25,
    city: "New York"
};

console.log(person.name);   // "John"
console.log(person.age);    // 25
console.log(person.city);   // "New York"
```

**When to use:**
- Property names are valid identifiers (no spaces, no special characters)
- You know the property name in advance

---

### B. Bracket Notation
```javascript
let person = {
    name: "John",
    age: 25,
    "favorite color": "blue"  // Property with space
};

console.log(person["name"]);            // "John"
console.log(person["age"]);             // 25
console.log(person["favorite color"]);  // "blue"

// Using variables
let property = "name";
console.log(person[property]);  // "John"
```

**When to use:**
- Property names have spaces or special characters
- Property name is stored in a variable
- Dynamic property access

---

### Comparison: Dot vs Bracket
```javascript
let user = {
    name: "Alice",
    "user-id": 12345
};

// Dot notation
console.log(user.name);  // ✅ Works

// Bracket notation
console.log(user["name"]);     // ✅ Works
console.log(user["user-id"]);  // ✅ Works (only way for this property)

// This won't work:
// console.log(user.user-id);  // ❌ ERROR
```

## 4. Adding & Modifying Properties

### A. Adding New Properties
```javascript
let person = {
    name: "John",
    age: 25
};

// Add new properties
person.city = "New York";
person["country"] = "USA";
person.email = "john@example.com";

console.log(person);
// {
//     name: "John",
//     age: 25,
//     city: "New York",
//     country: "USA",
//     email: "john@example.com"
// }
```

### B. Modifying Existing Properties
```javascript
let car = {
    brand: "Toyota",
    year: 2020,
    color: "red"
};

// Modify properties
car.year = 2023;
car["color"] = "blue";

console.log(car);
// {brand: "Toyota", year: 2023, color: "blue"}
```

## 5. Deleting Properties

Use the `delete` operator to remove properties.
```javascript
let person = {
    name: "John",
    age: 25,
    city: "New York",
    email: "john@example.com"
};

delete person.email;
delete person["city"];

console.log(person);
// {name: "John", age: 25}
```

## 6. Checking if Property Exists

### A. `in` Operator
```javascript
let person = {
    name: "John",
    age: 25
};

console.log("name" in person);     // true
console.log("age" in person);      // true
console.log("email" in person);    // false
```

### B. `hasOwnProperty()` Method
```javascript
let person = {
    name: "John",
    age: 25
};

console.log(person.hasOwnProperty("name"));   // true
console.log(person.hasOwnProperty("email"));  // false
```

### C. Checking for `undefined`
```javascript
let person = {
    name: "John",
    age: 25
};

console.log(person.name !== undefined);   // true
console.log(person.email !== undefined);  // false
```

## 7. Looping Through Objects

### A. `for...in` Loop (Iterate Over Keys)

Best way to iterate through object properties.
```javascript
let person = {
    name: "John",
    age: 25,
    city: "New York"
};

for (let key in person) {
    console.log(key);  // Property name
    console.log(person[key]);  // Property value
}

// Output:
// name
// John
// age
// 25
// city
// New York
```

**Practical Example:**
```javascript
let product = {
    name: "Laptop",
    price: 999,
    brand: "Dell",
    inStock: true
};

for (let key in product) {
    console.log(`${key}: ${product[key]}`);
}
// Output:
// name: Laptop
// price: 999
// brand: Dell
// inStock: true
```

---

### B. `Object.keys()` - Get All Keys

Returns an **array** of all property names.
```javascript
let person = {
    name: "John",
    age: 25,
    city: "New York"
};

let keys = Object.keys(person);
console.log(keys);  // ["name", "age", "city"]

// Loop through keys
for (let key of keys) {
    console.log(`${key}: ${person[key]}`);
}
```

---

### C. `Object.values()` - Get All Values

Returns an **array** of all property values.
```javascript
let person = {
    name: "John",
    age: 25,
    city: "New York"
};

let values = Object.values(person);
console.log(values);  // ["John", 25, "New York"]

// Loop through values
for (let value of values) {
    console.log(value);
}
```

---

### D. `Object.entries()` - Get Key-Value Pairs

Returns an **array of arrays** (each inner array has [key, value]).
```javascript
let person = {
    name: "John",
    age: 25,
    city: "New York"
};

let entries = Object.entries(person);
console.log(entries);
// [
//     ["name", "John"],
//     ["age", 25],
//     ["city", "New York"]
// ]

// Loop through entries
for (let [key, value] of entries) {
    console.log(`${key}: ${value}`);
}
// name: John
// age: 25
// city: New York
```

## 8. Nested Objects

Objects can contain other objects.
```javascript
let company = {
    name: "Tech Corp",
    founded: 2010,
    address: {
        street: "123 Main St",
        city: "San Francisco",
        country: "USA"
    },
    ceo: {
        name: "Jane Doe",
        age: 45
    }
};

// Accessing nested properties
console.log(company.name);              // "Tech Corp"
console.log(company.address.city);      // "San Francisco"
console.log(company.ceo.name);          // "Jane Doe"

// Using bracket notation
console.log(company["address"]["street"]);  // "123 Main St"
```

## 9. Objects with Arrays
```javascript
let student = {
    name: "Alice",
    age: 20,
    grades: [85, 90, 92, 88],
    courses: ["Math", "Physics", "Chemistry"]
};

// Accessing array properties
console.log(student.grades[0]);     // 85

// Loop through array inside object
for (let grade of student.grades) {
    console.log(grade);
}
// 85, 90, 92, 88
```

## 10. Arrays of Objects

Very common pattern in real applications.
```javascript
let students = [
    {name: "Alice", age: 20, grade: 85},
    {name: "Bob", age: 22, grade: 90},
    {name: "Charlie", age: 21, grade: 88}
];

// Access specific student
console.log(students[0].name);   // "Alice"
console.log(students[1].grade);  // 90

// Loop through array of objects
for (let student of students) {
    console.log(`${student.name}: ${student.grade}`);
}
// Alice: 85
// Bob: 90
// Charlie: 88

// Using for...in on each object
for (let i = 0; i < students.length; i++) {
    console.log(`Student ${i + 1}:`);
    for (let key in students[i]) {
        console.log(`  ${key}: ${students[i][key]}`);
    }
}
```

## 11. Object Methods

Objects can contain **functions** as properties (called **methods**).
```javascript
let person = {
    name: "John",
    age: 25,
    greet: function() {
        console.log("Hello!");
    },
    introduce: function() {
        console.log("My name is " + this.name);
    }
};

// Call methods
person.greet();      // "Hello!"
person.introduce();  // "My name is John"
```

**Shorthand syntax (ES6):**
```javascript
let person = {
    name: "John",
    age: 25,
    greet() {
        console.log("Hello!");
    },
    introduce() {
        console.log("My name is " + this.name);
    }
};
```

## 12. Copying Objects

### A. Shallow Copy
```javascript
// Method 1: Object.assign()
let original = {name: "John", age: 25};
let copy1 = Object.assign({}, original);

// Method 2: Spread operator (ES6)
let copy2 = {...original};

console.log(copy1);  // {name: "John", age: 25}
console.log(copy2);  // {name: "John", age: 25}

// Modifying copy doesn't affect original
copy1.name = "Alice";
console.log(original.name);  // Still "John"
```

**⚠️ Warning with Nested Objects:**
```javascript
let person = {
    name: "John",
    address: {
        city: "New York"
    }
};

let copy = {...person};
copy.address.city = "Boston";

console.log(person.address.city);  // "Boston" (nested objects are referenced!)
```

## 13. Merging Objects
```javascript
let obj1 = {a: 1, b: 2};
let obj2 = {c: 3, d: 4};
let obj3 = {e: 5};

// Using Object.assign()
let merged1 = Object.assign({}, obj1, obj2, obj3);
console.log(merged1);  // {a: 1, b: 2, c: 3, d: 4, e: 5}

// Using spread operator
let merged2 = {...obj1, ...obj2, ...obj3};
console.log(merged2);  // {a: 1, b: 2, c: 3, d: 4, e: 5}
```

## 14. Common Object Patterns

### Pattern 1: Count Properties
```javascript
let person = {
    name: "John",
    age: 25,
    city: "New York"
};

let count = Object.keys(person).length;
console.log(count);  // 3
```

### Pattern 2: Check if Object is Empty
```javascript
let obj = {};

let isEmpty = Object.keys(obj).length === 0;
console.log(isEmpty);  // true
```

### Pattern 3: Filter Object Properties
```javascript
let person = {
    name: "John",
    age: 25,
    city: "New York",
    country: "USA"
};

let filtered = {};
for (let key in person) {
    if (key !== "country") {
        filtered[key] = person[key];
    }
}

console.log(filtered);  // {name: "John", age: 25, city: "New York"}
```

### Pattern 4: Transform Object Values
```javascript
let prices = {
    apple: 1.5,
    banana: 0.8,
    orange: 2.0
};

let discounted = {};
for (let key in prices) {
    discounted[key] = prices[key] * 0.9;  // 10% discount
}

console.log(discounted);
// {apple: 1.35, banana: 0.72, orange: 1.8}
```

## 15. Real-World Examples

### Example 1: User Profile
```javascript
let user = {
    username: "john_doe",
    email: "john@example.com",
    age: 28,
    isActive: true,
    preferences: {
        theme: "dark",
        language: "en",
        notifications: true
    }
};

console.log(`Username: ${user.username}`);
console.log(`Theme: ${user.preferences.theme}`);
```

### Example 2: Product Inventory
```javascript
let products = [
    {id: 1, name: "Laptop", price: 999, stock: 5},
    {id: 2, name: "Mouse", price: 25, stock: 50},
    {id: 3, name: "Keyboard", price: 75, stock: 30}
];

// Find total inventory value
let totalValue = 0;
for (let product of products) {
    totalValue += product.price * product.stock;
}

console.log(`Total Inventory Value: $${totalValue}`);
```

### Example 3: Student Records
```javascript
let students = {
    "S001": {name: "Alice", grade: 85},
    "S002": {name: "Bob", grade: 90},
    "S003": {name: "Charlie", grade: 78}
};

// Find student by ID
let studentId = "S002";
console.log(students[studentId].name);  // "Bob"

// Calculate average grade
let total = 0;
let count = 0;

for (let id in students) {
    total += students[id].grade;
    count++;
}

let average = total / count;
console.log(`Average Grade: ${average}`);
```

## 💡 Key Takeaways

### ✅ Object Basics
- Objects store **key-value pairs** (properties)
- Keys are strings (or Symbols)
- Values can be any data type (strings, numbers, arrays, objects, functions)

### ✅ Accessing Properties
- **Dot notation**: `object.property` (most common)
- **Bracket notation**: `object["property"]` (for dynamic access or special characters)

### ✅ Modifying Objects
- **Add**: `object.newProperty = value`
- **Update**: `object.existingProperty = newValue`
- **Delete**: `delete object.property`

### ✅ Checking Properties
- `"property" in object`
- `object.hasOwnProperty("property")`
- `object.property !== undefined`

### ✅ Looping Through Objects
- **`for...in`**: Loop through keys
- **`Object.keys()`**: Get array of keys
- **`Object.values()`**: Get array of values
- **`Object.entries()`**: Get array of [key, value] pairs

### ✅ Object vs Array

| Feature | Object | Array |
|---------|--------|-------|
| Structure | Key-value pairs | Indexed list |
| Access | `obj.key` or `obj["key"]` | `arr[index]` |
| Order | Not guaranteed (modern JS: insertion order) | Guaranteed |
| Best for | Related properties | Ordered lists |
| Loop | `for...in` | `for...of`, `for` loop |
