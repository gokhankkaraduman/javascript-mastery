## 1. Loops: Repeating Actions

Loops allow you to execute a block of code multiple times without writing it repeatedly.

### A. `for` Loop

The most common loop. Best when you know how many times you want to iterate.

**Syntax:**
```javascript
for (initialization; condition; increment) {
    // code to execute
}
```

**Example:**
```javascript
// Print numbers 1 to 5
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
// Output: 1 2 3 4 5
```

**How it works:**
1. **Initialization:** `let i = 1` (runs once at the start)
2. **Condition:** `i <= 5` (checked before each iteration)
3. **Code block:** executes if condition is true
4. **Increment:** `i++` (runs after each iteration)

**More Examples:**
```javascript
// Count backwards
for (let i = 10; i >= 1; i--) {
    console.log(i);
}

// Loop through a string
let word = "Hello";
for (let i = 0; i < word.length; i++) {
    console.log(word[i]);
}
// Output: H e l l o

// Loop through an array
let fruits = ["apple", "banana", "orange"];
for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
```

---

### B. `while` Loop

Executes as long as the condition is true. Best when you don't know how many iterations you need.

**Syntax:**
```javascript
while (condition) {
    // code to execute
}
```

**Example:**
```javascript
let count = 1;

while (count <= 5) {
    console.log(count);
    count++;
}
// Output: 1 2 3 4 5
```

**⚠️ Warning:** Make sure the condition eventually becomes false, or you'll create an infinite loop!
```javascript
// ❌ INFINITE LOOP - DON'T RUN THIS
while (true) {
    console.log("This never stops!");
}

// ✅ CORRECT
let i = 0;
while (i < 5) {
    console.log(i);
    i++; // Don't forget to increment!
}
```

**Real-world example:**
```javascript
// Keep asking until valid input
let password = "";

while (password.length < 6) {
    console.log("Password must be at least 6 characters");
    password = "abc123"; // In real app, you'd get user input
}
```

---

### C. `do...while` Loop

Similar to `while`, but **always executes at least once** because the condition is checked at the end.

**Syntax:**
```javascript
do {
    // code to execute
} while (condition);
```

**Example:**
```javascript
let num = 1;

do {
    console.log(num);
    num++;
} while (num <= 5);
// Output: 1 2 3 4 5
```

**Key Difference:**
```javascript
// while loop
let x = 10;
while (x < 5) {
    console.log(x); // Never executes
}

// do...while loop
let y = 10;
do {
    console.log(y); // Executes once: 10
} while (y < 5);
```

**When to use `do...while`:**
When you need the code to run at least once, regardless of the condition.
```javascript
let choice;
do {
    console.log("Menu: 1. Start 2. Exit");
    choice = 2; // Simulating user input
} while (choice !== 2);
```

## 2. Loop Control: `break` and `continue`

These keywords give you more control over loop execution.

### A. `break` Statement

**Immediately exits the loop**, regardless of the condition.
```javascript
// Stop when finding a specific value
for (let i = 1; i <= 10; i++) {
    if (i === 5) {
        break; // Exit loop when i is 5
    }
    console.log(i);
}
// Output: 1 2 3 4
```

**Real-world example:**
```javascript
// Search for a value in an array
let numbers = [10, 20, 30, 40, 50];
let target = 30;
let found = false;

for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] === target) {
        console.log("Found at index: " + i);
        found = true;
        break; // Stop searching once found
    }
}
```

---

### B. `continue` Statement

**Skips the current iteration** and moves to the next one.
```javascript
// Skip even numbers, only print odd
for (let i = 1; i <= 10; i++) {
    if (i % 2 === 0) {
        continue; // Skip even numbers
    }
    console.log(i);
}
// Output: 1 3 5 7 9
```

**Another example:**
```javascript
// Skip negative numbers
let numbers = [5, -3, 8, -1, 12, -7, 4];

for (let i = 0; i < numbers.length; i++) {
    if (numbers[i] < 0) {
        continue; // Skip negative numbers
    }
    console.log(numbers[i]);
}
// Output: 5 8 12 4
```

---

### `break` vs `continue` Summary

| Keyword | Action | Use Case |
|---------|--------|----------|
| `break` | Exits the loop completely | Stop when you found what you need |
| `continue` | Skips current iteration, continues loop | Skip certain values but keep going |

## 3. String Methods (Complete Guide)

Strings have many built-in methods for manipulation and analysis.

### A. Case Conversion
```javascript
let text = "JavaScript";

text.toUpperCase()    // "JAVASCRIPT"
text.toLowerCase()    // "javascript"
```

---

### B. Searching & Checking
```javascript
let sentence = "I love JavaScript programming";

// Check if string contains a substring
sentence.includes("Java")        // true
sentence.includes("Python")      // false

// Find index of substring (first occurrence)
sentence.indexOf("love")         // 2
sentence.indexOf("Java")         // 7
sentence.indexOf("Python")       // -1 (not found)

// Find index from the end (last occurrence)
sentence.lastIndexOf("a")        // 18

// Check if string starts with substring
sentence.startsWith("I love")    // true
sentence.startsWith("You")       // false

// Check if string ends with substring
sentence.endsWith("programming") // true
sentence.endsWith("Java")        // false
```

---

### C. Extracting Parts
```javascript
let text = "JavaScript";

// Get character at index
text.charAt(0)           // "J"
text.charAt(4)           // "S"
text[0]                  // "J" (alternative)

// Get character code (ASCII/Unicode)
text.charCodeAt(0)       // 74 (code for 'J')

// Extract substring
text.substring(0, 4)     // "Java" (from index 0 to 4, not including 4)
text.substring(4)        // "Script" (from index 4 to end)

// Slice (similar to substring, but can use negative indices)
text.slice(0, 4)         // "Java"
text.slice(4)            // "Script"
text.slice(-6)           // "Script" (last 6 characters)
text.slice(-6, -2)       // "Scri"

// Extract portion (older method, similar to slice)
text.substr(0, 4)        // "Java" (start at 0, take 4 characters)
text.substr(4, 6)        // "Script"
```

---

### D. Modifying & Replacing
```javascript
let message = "Hello World";

// Replace first occurrence
message.replace("World", "JavaScript")  // "Hello JavaScript"

// Replace all occurrences (need to use replaceAll or regex)
let text = "cat cat cat";
text.replaceAll("cat", "dog")          // "dog dog dog"

// Trim whitespace from both ends
let spaced = "   Hello   ";
spaced.trim()              // "Hello"
spaced.trimStart()         // "Hello   "
spaced.trimEnd()           // "   Hello"

// Pad string to certain length
let num = "5";
num.padStart(3, "0")       // "005"
num.padEnd(3, "0")         // "500"

// Repeat string
"Ha".repeat(3)             // "HaHaHa"
```

---

### E. Splitting & Joining
```javascript
// Split string into array
let sentence = "I love JavaScript";
sentence.split(" ")        // ["I", "love", "JavaScript"]
sentence.split("")         // ["I", " ", "l", "o", "v", "e", ...]

let csv = "apple,banana,orange";
csv.split(",")             // ["apple", "banana", "orange"]

// Joining is array method, but useful with strings
let words = ["Hello", "World"];
words.join(" ")            // "Hello World"
words.join("-")            // "Hello-World"
```

---

### F. Other Useful Methods
```javascript
let text = "JavaScript";

// Get length (property, not method)
text.length                // 10

// Concatenate (combine strings)
text.concat(" is ", "fun") // "JavaScript is fun"
"Hello".concat(" World")   // "Hello World"

// Alternative: use + operator
"Hello" + " " + "World"    // "Hello World"

// Convert to array of characters
text.split("")             // ["J", "a", "v", "a", ...]
Array.from(text)           // ["J", "a", "v", "a", ...]

// Check if string matches pattern (returns boolean)
let email = "test@example.com";
email.includes("@")        // true
```

## 4. Combining Loops & String Methods

**Example 1: Count vowels in a string**
```javascript
function countVowels(str) {
    let count = 0;
    let vowels = "aeiouAEIOU";
    
    for (let i = 0; i < str.length; i++) {
        if (vowels.includes(str[i])) {
            count++;
        }
    }
    
    return count;
}

console.log(countVowels("Hello World")); // 3
```

**Example 2: Reverse a string**
```javascript
function reverseString(str) {
    let reversed = "";
    
    for (let i = str.length - 1; i >= 0; i--) {
        reversed += str[i];
    }
    
    return reversed;
}

console.log(reverseString("Hello")); // "olleH"
```

**Example 3: Find longest word in sentence**
```javascript
function findLongestWord(sentence) {
    let words = sentence.split(" ");
    let longest = "";
    
    for (let i = 0; i < words.length; i++) {
        if (words[i].length > longest.length) {
            longest = words[i];
        }
    }
    
    return longest;
}

console.log(findLongestWord("I love JavaScript programming")); 
// "programming"
```

**Example 4: Remove all spaces from string**
```javascript
function removeSpaces(str) {
    let result = "";
    
    for (let i = 0; i < str.length; i++) {
        if (str[i] !== " ") {
            result += str[i];
        }
    }
    
    return result;
}

console.log(removeSpaces("Hello World")); // "HelloWorld"

// Or simply:
"Hello World".replaceAll(" ", ""); // "HelloWorld"
```

## 💡 Key Takeaways

### ✅ `for` Loop
- Best when you know the number of iterations
- Has three parts: initialization, condition, increment
- Most commonly used loop

### ✅ `while` Loop
- Best when you don't know how many iterations
- Checks condition BEFORE executing
- Watch out for infinite loops!

### ✅ `do...while` Loop
- Checks condition AFTER executing
- Always runs at least once
- Useful for menus and validation

### ✅ `break` Statement
- Exits the loop immediately
- Use when you found what you're looking for

### ✅ `continue` Statement
- Skips current iteration
- Use to skip certain values

### ✅ String Methods Categories
1. **Case:** `toUpperCase()`, `toLowerCase()`
2. **Search:** `includes()`, `indexOf()`, `startsWith()`, `endsWith()`
3. **Extract:** `charAt()`, `substring()`, `slice()`, `substr()`
4. **Modify:** `replace()`, `replaceAll()`, `trim()`, `repeat()`
5. **Split/Join:** `split()`, `concat()`

## 📊 Loop Comparison Table

| Loop Type | When to Use | Condition Check |
|-----------|-------------|-----------------|
| `for` | Known iterations | Before each iteration |
| `while` | Unknown iterations | Before each iteration |
| `do...while` | Need to run at least once | After each iteration |

## 🎯 Common Loop Patterns
```javascript
// Pattern 1: Iterate through array
for (let i = 0; i < array.length; i++) {
    console.log(array[i]);
}

// Pattern 2: Iterate through string
for (let i = 0; i < string.length; i++) {
    console.log(string[i]);
}

// Pattern 3: Count up
for (let i = 0; i <= 10; i++) {
    console.log(i);
}

// Pattern 4: Count down
for (let i = 10; i >= 0; i--) {
    console.log(i);
}

// Pattern 5: Iterate by step
for (let i = 0; i <= 100; i += 10) {
    console.log(i); // 0, 10, 20, 30...
}
```
