# 🚀 Day 14 of 365: Introduction to OOP in JavaScript

Today we begin our journey into **Object-Oriented Programming (OOP)** in JavaScript. We're covering the fundamentals - the building blocks that will help us write more organized and reusable code.

---

## 1. What is Object-Oriented Programming?

**OOP** is a programming paradigm that organizes code around **objects** rather than functions and logic. Objects bundle related data (properties) and behavior (methods) together.

### Why Use OOP?

- **Organization**: Group related code together
- **Reusability**: Create templates for similar objects
- **Maintainability**: Easier to update and debug
- **Real-world modeling**: Represents real entities (users, products, etc.)

---

## 2. Objects Review

Before diving into OOP, let's review basic objects.
```javascript
// Simple object
let person = {
    name: "John",
    age: 30,
    greet: function() {
        console.log("Hello, I'm " + this.name);
    }
};

person.greet();  // "Hello, I'm John"
```

**Problem with this approach:**
- Can't easily create multiple similar objects
- Code duplication
- Hard to maintain

**Solution:** Use constructors and classes!

## 3. Constructor Functions (Old Way)

**Constructor functions** are regular functions used to create objects.

### A. Basic Constructor
```javascript
// Constructor function (capitalized by convention)
function Person(name, age) {
    this.name = name;
    this.age = age;
    this.greet = function() {
        console.log("Hello, I'm " + this.name);
    };
}

// Create objects using 'new' keyword
let person1 = new Person("Alice", 25);
let person2 = new Person("Bob", 30);

person1.greet();  // "Hello, I'm Alice"
person2.greet();  // "Hello, I'm Bob"

console.log(person1.name);  // "Alice"
console.log(person2.age);   // 30
```

**Key Points:**
- Function name starts with **capital letter** (convention)
- Use `this` to refer to the new object
- Use `new` keyword to create instances
- Each instance is independent

---

### B. How 'new' Works

When you use `new`, JavaScript:
1. Creates a new empty object
2. Sets `this` to point to that object
3. Executes the constructor function
4. Returns the object
```javascript
function Car(brand, model) {
    // 'this' refers to the new object being created
    this.brand = brand;
    this.model = model;
}

let myCar = new Car("Toyota", "Camry");
console.log(myCar);  // {brand: "Toyota", model: "Camry"}
```

---

### C. Adding Methods
```javascript
function User(username, email) {
    this.username = username;
    this.email = email;
    
    this.getInfo = function() {
        return this.username + " (" + this.email + ")";
    };
    
    this.updateEmail = function(newEmail) {
        this.email = newEmail;
    };
}

let user1 = new User("alice", "alice@example.com");
console.log(user1.getInfo());  // "alice (alice@example.com)"

user1.updateEmail("alice.new@example.com");
console.log(user1.getInfo());  // "alice (alice.new@example.com)"
```

### D. Multiple Instances
```javascript
function Product(name, price) {
    this.name = name;
    this.price = price;
    
    this.getPrice = function() {
        return "$" + this.price;
    };
    
    this.applyDiscount = function(percent) {
        this.price = this.price * (1 - percent / 100);
    };
}

let laptop = new Product("Laptop", 1000);
let mouse = new Product("Mouse", 25);

console.log(laptop.getPrice());  // "$1000"
console.log(mouse.getPrice());   // "$25"

laptop.applyDiscount(10);
console.log(laptop.getPrice());  // "$900"
```

## 4. The 'this' Keyword in Constructors

`this` refers to the **object being created**.
```javascript
function Counter(start) {
    this.count = start;
    
    this.increment = function() {
        this.count++;  // 'this' refers to the counter object
    };
    
    this.getValue = function() {
        return this.count;
    };
}

let counter1 = new Counter(0);
let counter2 = new Counter(10);

counter1.increment();
counter1.increment();
console.log(counter1.getValue());  // 2

counter2.increment();
console.log(counter2.getValue());  // 11
```

## 5. Class Syntax (Modern Way - ES6)

**Classes** provide a cleaner syntax for creating objects. They do the same thing as constructor functions but look more organized.

### A. Basic Class
```javascript
class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }
    
    greet() {
        console.log("Hello, I'm " + this.name);
    }
    
    getInfo() {
        return `${this.name} is ${this.age} years old`;
    }
}

// Create instances
let person1 = new Person("Alice", 25);
let person2 = new Person("Bob", 30);

person1.greet();  // "Hello, I'm Alice"
console.log(person2.getInfo());  // "Bob is 30 years old"
```

---

### B. Class vs Constructor Function
```javascript
// Constructor Function (old way)
function Dog(name, breed) {
    this.name = name;
    this.breed = breed;
    this.bark = function() {
        console.log(this.name + " says Woof!");
    };
}

// Class (modern way)
class DogClass {
    constructor(name, breed) {
        this.name = name;
        this.breed = breed;
    }
    
    bark() {
        console.log(this.name + " says Woof!");
    }
}

// Both work the same way
let dog1 = new Dog("Max", "Labrador");
let dog2 = new DogClass("Buddy", "Golden Retriever");

dog1.bark();  // "Max says Woof!"
dog2.bark();  // "Buddy says Woof!"
```

**Differences:**
- Classes have cleaner syntax
- Methods are defined without `function` keyword
- Constructor is defined with `constructor()` method
- Modern and recommended approach

### C. Multiple Methods
```javascript
class BankAccount {
    constructor(owner, balance) {
        this.owner = owner;
        this.balance = balance;
    }
    
    deposit(amount) {
        this.balance += amount;
        console.log(`Deposited: $${amount}`);
    }
    
    withdraw(amount) {
        if (amount > this.balance) {
            console.log("Insufficient funds!");
            return;
        }
        this.balance -= amount;
        console.log(`Withdrew: $${amount}`);
    }
    
    getBalance() {
        return `Balance: $${this.balance}`;
    }
}

let account = new BankAccount("Alice", 1000);
console.log(account.getBalance());  // "Balance: $1000"

account.deposit(500);
console.log(account.getBalance());  // "Balance: $1500"

account.withdraw(200);
console.log(account.getBalance());  // "Balance: $1300"

account.withdraw(2000);  // "Insufficient funds!"
```

### D. Practical Example: Shopping Cart
```javascript
class ShoppingCart {
    constructor() {
        this.items = [];
    }
    
    addItem(name, price, quantity) {
        this.items.push({
            name: name,
            price: price,
            quantity: quantity
        });
        console.log(`Added ${quantity} ${name}(s) to cart`);
    }
    
    removeItem(name) {
        this.items = this.items.filter(item => item.name !== name);
        console.log(`Removed ${name} from cart`);
    }
    
    getTotal() {
        let total = 0;
        for (let item of this.items) {
            total += item.price * item.quantity;
        }
        return total;
    }
    
    showCart() {
        console.log("Cart items:");
        for (let item of this.items) {
            console.log(`  ${item.name}: $${item.price} x ${item.quantity}`);
        }
        console.log(`Total: $${this.getTotal()}`);
    }
}

let cart = new ShoppingCart();
cart.addItem("Laptop", 999, 1);
cart.addItem("Mouse", 25, 2);
cart.addItem("Keyboard", 75, 1);
cart.showCart();
// Cart items:
//   Laptop: $999 x 1
//   Mouse: $25 x 2
//   Keyboard: $75 x 1
// Total: $1124
```

## 6. Creating Multiple Instances

The power of OOP: easily create multiple similar objects.
```javascript
class Student {
    constructor(name, grade) {
        this.name = name;
        this.grade = grade;
    }
    
    study() {
        console.log(this.name + " is studying");
    }
    
    getGrade() {
        return `${this.name}'s grade: ${this.grade}`;
    }
}

// Create multiple students
let student1 = new Student("Alice", "A");
let student2 = new Student("Bob", "B");
let student3 = new Student("Charlie", "A");

student1.study();  // "Alice is studying"
console.log(student2.getGrade());  // "Bob's grade: B"
console.log(student3.getGrade());  // "Charlie's grade: A"
```

## 7. Practical Examples

### Example 1: Todo Item

class Todo {
    constructor(text) {
        this.text = text;

### Example 2: Book
```javascript
class Book {
    constructor(title, author, pages) {
        this.title = title;
        this.author = author;
        this.pages = pages;
        this.currentPage = 0;
    }
    
    read(pages) {
        this.currentPage += pages;
        if (this.currentPage > this.pages) {
            this.currentPage = this.pages;
        }
        console.log(`Read ${pages} pages. Now at page ${this.currentPage}`);
    }
    
    getProgress() {
        let percent = (this.currentPage / this.pages) * 100;
        return `${percent.toFixed(1)}% complete`;
    }
    
    isFinished() {
        return this.currentPage >= this.pages;
    }
}

let book = new Book("JavaScript Guide", "John Doe", 300);
book.read(50);
console.log(book.getProgress());  // "16.7% complete"
book.read(250);
console.log(book.getProgress());  // "100.0% complete"
console.log(book.isFinished());   // true
```

## 8. Default Values

You can provide default values in the constructor.
```javascript
class Settings {
    constructor(theme = "light", language = "en", fontSize = 14) {
        this.theme = theme;
        this.language = language;
        this.fontSize = fontSize;
    }
    
    getSettings() {
        return {
            theme: this.theme,
            language: this.language,
            fontSize: this.fontSize
        };
    }
}

let settings1 = new Settings();
console.log(settings1.getSettings());
// {theme: "light", language: "en", fontSize: 14}

let settings2 = new Settings("dark", "es", 16);
console.log(settings2.getSettings());
// {theme: "dark", language: "es", fontSize: 16}

let settings3 = new Settings("dark");
console.log(settings3.getSettings());
// {theme: "dark", language: "en", fontSize: 14}
```

## 9. Checking Instance Type

Use `instanceof` to check if object was created from a class.
```javascript
class Car {
    constructor(brand) {
        this.brand = brand;
    }
}

class Bike {
    constructor(brand) {
        this.brand = brand;
    }
}

let myCar = new Car("Toyota");
let myBike = new Bike("Honda");

console.log(myCar instanceof Car);   // true
console.log(myCar instanceof Bike);  // false
console.log(myBike instanceof Bike); // true
```

## 🎯 Common Patterns

### Pattern 1: Simple Class
```javascript
class ClassName {
    constructor(property1, property2) {
        this.property1 = property1;
        this.property2 = property2;
    }
    
    method1() {
        // do something
    }
}
```

### Pattern 2: Class with Default Values
```javascript
class ClassName {
    constructor(value = defaultValue) {
        this.value = value;
    }
}
```

### Pattern 3: Creating Instances
```javascript
let instance1 = new ClassName(args);
let instance2 = new ClassName(args);
```

---

## 📊 Constructor Function vs Class

| Feature | Constructor Function | Class |
|---------|---------------------|-------|
| Syntax | `function Name() {}` | `class Name {}` |
| Constructor | The function itself | `constructor() {}` method |
| Methods | `this.method = function() {}` | `method() {}` |
| Modern | No | Yes (ES6+) |
| Recommended | For legacy code | ✅ Yes |
