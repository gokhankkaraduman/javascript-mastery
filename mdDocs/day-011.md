## 🛠️ Key Implementation Highlights



### The Power of "Pipe" and "Compose"
Instead of unreadable nested function calls, I implemented a cleaner approach to handle transformations:
- **Compose:** Executes right-to-left.
- **Pipe:** Executes left-to-right (more intuitive for data flow).

### Safely Handling Nested Data
Accessing deep object properties in large datasets can be risky. I built a utility to handle this gracefully without crashing the application:
`getNestedProperty(data, "user.profile.settings.theme"); // Returns value or undefined`
