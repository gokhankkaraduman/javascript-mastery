### 1. console.log() - Debugging Tool

Using console.log() to output to the console:

// Basic usage

### 2. Variable Declaration: let vs const

#### const (Constant)
- **Cannot be reassigned**
- Block-scoped
- Must be initialized during declaration
- **Default choice:** Use const for values that won't change

const PI = 3.14159;
const userName = "Gökhan";
const isStudent = false;

// ❌ Error:
// PI = 3.14;  // TypeError: Assignment to constant variable

// ✅ Objects and arrays declared with const can have their contents modified:
const person = { name: "John" };
person.name = "Jane";              // ✅ Works
person.age = 30;                   // ✅ Works

const colors = ["red", "blue"];
colors.push("green");              // ✅ Works
// colors = ["yellow"];            // ❌ Error

#### let (Variable)
- **Can be reassigned**
- Block-scoped
- Use only when the value needs to change

let age = 29;
age = 30;                          // ✅ Works

let counter = 0;
counter = counter + 1;             // ✅ Works

let status = "pending";
status = "completed";              // ✅ Works

**📌 Rule:** Use const by default, only use let when the value needs to change.

### 3. Primitive Data Types

JavaScript has 7 primitive data types:

#### 1. String (Text)

let name = "Gökhan";
let city = 'Ankara';
let message = `Hello, ${name}!`;   // Template string

console.log(typeof name);          // "string"

#### 2. Number

let age = 29;
let price = 19.99;
let negative = -42;
let infinity = Infinity;
let notANumber = NaN;              // Not a Number

console.log(typeof age);           // "number"
console.log(typeof price);         // "number"

#### 3. Boolean

let isActive = true;
let isCompleted = false;

console.log(typeof isActive);      // "boolean"

#### 4. Undefined

let x;                             // No value assigned
console.log(x);                    // undefined
console.log(typeof x);             // "undefined"

let user = {
  name: "Gökhan"
};
console.log(user.age);             // undefined (non-existent property)

#### 5. Null

let emptyValue = null;             // Intentionally "empty" value
console.log(emptyValue);           // null
console.log(typeof emptyValue);    // "object" (JavaScript bug)

#### 6. Symbol (ES6)

let id1 = Symbol("id");
let id2 = Symbol("id");
console.log(id1 === id2);          // false (each Symbol is unique)

#### 7. BigInt (ES2020)

let bigNumber = 1234567890123456789012345678901234567890n;
console.log(typeof bigNumber);     // "bigint"

### 4. Naming Conventions

Different methods used for naming variables in JavaScript:

#### camelCase (JavaScript Standard) ✅
- First word lowercase, first letter of subsequent words capitalized
- **Used in JavaScript**

// ✅ Use in JavaScript:
let firstName = "Gökhan";
let userAge = 29;
let isLoggedIn = true;
let totalPriceWithTax = 150;
let getUserData = function() {};

#### kebab-case (Used in HTML/CSS)
- Words separated by hyphens (-)
- **Cannot be used as variable names in JavaScript!**

// ❌ Doesn't work in JavaScript:
// let first-name = "Gökhan";  // SyntaxError

// ✅ But used in HTML/CSS:
// <div class="user-profile"></div>
// .main-container { ... }

#### snake_case (Used in Python)
- Words separated by underscores (_)
- Works in JavaScript but **not the convention**

// ⚠️ Works in JavaScript but don't use:
let first_name = "Gökhan";         // Python style
let user_age = 29;

// ✅ Use camelCase instead:
let firstName = "Gökhan";
let userAge = 29;

#### PascalCase (For class names)
- First letter of each word capitalized
- Used **only for class/constructor names** in JavaScript

// ✅ Use for class names:
class UserProfile {}
class ShoppingCart {}
class PaymentProcessor {}

// ❌ Don't use for regular variables:
let UserName = "Gökhan";           // Wrong
let userName = "Gökhan";           // Correct

#### UPPER_SNAKE_CASE (For constants)
- All letters uppercase, separated by underscores
- Used for **unchanging constants**

// ✅ Use for constant values:
const API_KEY = "abc123xyz";
const MAX_USERS = 100;
const PI = 3.14159;
const DATABASE_URL = "mongodb://localhost:27017";

**📌 JavaScript Rule:** camelCase for variables, PascalCase for classes, UPPER_SNAKE_CASE for constants

### 5. typeof Operator

The typeof operator checks the data type of a variable:

// Checking data types
console.log(typeof "Hello");       // "string"
console.log(typeof 42);            // "number"
console.log(typeof 3.14);          // "number"
console.log(typeof true);          // "boolean"
console.log(typeof undefined);     // "undefined"
console.log(typeof null);          // "object" (known JavaScript bug)
console.log(typeof {});            // "object"
console.log(typeof []);            // "object"
console.log(typeof function(){});  // "function"

// Practical usage
let age = 25;
if (typeof age === "number") {
  console.log("Age is a number");
}

### 6. Type Conversion (Explicit vs Implicit)

#### Explicit Conversion (Manual Conversion)
Type conversion done intentionally by the developer:

// String to Number
let strNumber = "42";
let num1 = Number(strNumber);      // 42
let num2 = parseInt(strNumber);    // 42
let num3 = parseFloat("3.14");     // 3.14

// Number to String
let number = 42;
let str1 = String(number);         // "42"
let str2 = number.toString();      // "42"

// Boolean conversion
let bool1 = Boolean(1);            // true
let bool2 = Boolean(0);            // false
let bool3 = Boolean("hello");      // true
let bool4 = Boolean("");           // false

#### Implicit Conversion (Automatic Conversion)
Type conversion done automatically by JavaScript (Type Coercion):

// String concatenation
let result1 = "5" + 3;             // "53" (number -> string)
let result2 = "Hello" + " " + "World"; // "Hello World"

// Mathematical operations
let result3 = "10" - 5;            // 5 (string -> number)
let result4 = "10" * "2";          // 20 (string -> number)
let result5 = "20" / "4";          // 5 (string -> number)

// Boolean context
if ("hello") {                     // "hello" -> true
  console.log("Truthy value");
}

if (0) {                           // 0 -> false
  console.log("Won't execute");
}

**⚠️ Warning:** Implicit conversion can sometimes produce unexpected results; explicit conversion is safer.

### 7. Mathematical Operators

#### Basic Operators

// Subtraction

  console.log("Even number");
} else {
  console.log("Odd number");
}
