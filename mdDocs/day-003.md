# 🚀 Day 3 of 365: Control Flow & Conditional Logic

Today's journey dives into **Decision Making** in JavaScript. We explore how programs make choices using **conditionals**, **truthy/falsy values**, and **logical operators**. These are the building blocks that give your code intelligence.

---

## 1. Conditionals: Making Decisions

Conditionals allow your program to execute different code based on different conditions.

### A. The `if` Statement

The most basic form of decision-making.
```javascript
let age = 20;

if (age >= 18) {
    console.log("You are an adult");
}
// Output: You are an adult
```

### B. `if...else` Statement

Provides an alternative path when the condition is false.
```javascript
let temperature = 15;

if (temperature > 25) {
    console.log("It's hot outside");
} else {
    console.log("It's cool outside");
}
// Output: It's cool outside
```

### C. `if...else if...else` Chain

For multiple conditions.
```javascript
let score = 75;

if (score >= 90) {
    console.log("Grade: A");
} else if (score >= 80) {
    console.log("Grade: B");
} else if (score >= 70) {
    console.log("Grade: C");
} else if (score >= 60) {
    console.log("Grade: D");
} else {
    console.log("Grade: F");
}
// Output: Grade: C
```

## 2. The `switch` Statement

An alternative to multiple `if...else if` statements, especially useful when checking a single value against many possibilities.

### Syntax:
```javascript
switch (expression) {
    case value1:
        // code to execute
        break;
    case value2:
        // code to execute
        break;
    default:
        // code if no cases match
}
```

### Example:
```javascript
let day = 3;
let dayName;

switch (day) {
    case 1:
        dayName = "Monday";
        break;
    case 2:
        dayName = "Tuesday";
        break;
    case 3:
        dayName = "Wednesday";
        break;
    case 4:
        dayName = "Thursday";
        break;
    case 5:
        dayName = "Friday";
        break;
    case 6:
        dayName = "Saturday";
        break;
    case 7:
        dayName = "Sunday";
        break;
    default:
        dayName = "Invalid day";
}

console.log(dayName); // Output: Wednesday
```

### Important Notes:
- **`break`**: Stops the execution and exits the switch block. Without it, execution "falls through" to the next case.
- **`default`**: Optional, acts like the `else` in if statements.

## 3. Truthy and Falsy Values

In JavaScript, every value has an inherent boolean value when evaluated in a boolean context (like in `if` statements).

### Falsy Values (values that evaluate to `false`):
```javascript
false
0
-0
0n (BigInt zero)
"" (empty string)
null
undefined
NaN
```

### Truthy Values:
Everything else! Including:
```javascript
true
1, -1, 100 (any non-zero number)
"hello", "0", "false" (any non-empty string)
[] (empty array)
{} (empty object)
function() {} (any function)
```

### Using `Boolean()` to Check:
The `Boolean()` function explicitly converts a value to its boolean equivalent.
```javascript
console.log(Boolean(0));           // false
console.log(Boolean(""));          // false
console.log(Boolean(null));        // false
console.log(Boolean(undefined));   // false
console.log(Boolean(NaN));         // false

console.log(Boolean(1));           // true
console.log(Boolean("hello"));     // true
console.log(Boolean([]));          // true
console.log(Boolean({}));          // true
```

### Why Check Truthy/Falsy?
It helps you handle edge cases and validate data:
```javascript
let username = "";

if (username) {
    console.log("Welcome, " + username);
} else {
    console.log("Please enter a username");
}
// Output: Please enter a username
```

## 4. Logical Operators

Logical operators combine or invert boolean values.

### A. `&&` (AND Operator)

Returns `true` only if **BOTH** operands are true.
```javascript
let age = 25;
let hasLicense = true;

if (age >= 18 && hasLicense) {
    console.log("You can drive");
} else {
    console.log("You cannot drive");
}
// Output: You can drive
```

**Truth Table:**
```
true && true   → true
true && false  → false
false && true  → false
false && false → false
```

### B. `||` (OR Operator)

Returns `true` if **AT LEAST ONE** operand is true.
```javascript
let isWeekend = false;
let isHoliday = true;

if (isWeekend || isHoliday) {
    console.log("Time to relax!");
} else {
    console.log("Time to work");
}
// Output: Time to relax!
```

**Truth Table:**
```
true || true   → true
true || false  → true
false || true  → true
false || false → false
```

### C. `!` (NOT Operator)

Inverts the boolean value.
```javascript
let isRaining = false;

if (!isRaining) {
    console.log("Let's go outside!");
}
// Output: Let's go outside!

console.log(!true);   // false
console.log(!false);  // true
```

### Combining Logical Operators:
```javascript
let age = 25;
let hasTicket = true;
let isVIP = false;

if ((age >= 18 && hasTicket) || isVIP) {
    console.log("Entry granted");
} else {
    console.log("Entry denied");
}
// Output: Entry granted
```

---

## 5. Short-Circuit Evaluation

Logical operators don't always evaluate both operands.

### `&&` Short-Circuit:
If the first operand is `false`, the second is never evaluated.
```javascript
let user = null;
let userName = user && user.name; // user is null, so user.name is never accessed
console.log(userName); // null
```

### `||` Short-Circuit:
If the first operand is `true`, the second is never evaluated.
```javascript
let savedTheme = "";
let theme = savedTheme || "light"; // savedTheme is empty, so "light" is used
console.log(theme); // "light"
```

## 💡 Key Takeaways

### ✅ Conditionals (`if`, `else`, `else if`)
Allow your program to make decisions and execute different code based on conditions.

### ✅ `switch` Statement
A cleaner alternative to multiple `if...else if` statements when checking a single value against many cases. Always use `break` to prevent fall-through.

### ✅ Truthy and Falsy Values
- **Falsy:** `false`, `0`, `""`, `null`, `undefined`, `NaN`
- **Truthy:** Everything else
- Use `Boolean()` to explicitly check the truthiness of a value.

### ✅ Logical Operators
- **`&&` (AND):** Both conditions must be true
- **`||` (OR):** At least one condition must be true
- **`!` (NOT):** Inverts the boolean value

### ✅ Short-Circuit Evaluation
- `&&` stops at the first `false`
- `||` stops at the first `true`
- Useful for setting default values and preventing errors
