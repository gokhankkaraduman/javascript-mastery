## 1. Understanding 'this' Keyword

The **`this`** keyword refers to different things depending on **where and how** it's used.

### A. 'this' in Global Scope
```javascript
console.log(this);  // Window object (in browser)

function showThis() {
    console.log(this);  // Window object (in non-strict mode)
}

showThis();
```

---

### B. 'this' in Objects

In object methods, `this` refers to the **object itself**.
```javascript
let person = {
    name: "Alice",
    age: 25,
    greet: function() {
        console.log("Hello, I'm " + this.name);
        console.log("I'm " + this.age + " years old");
    }
};

person.greet();
// "Hello, I'm Alice"
// "I'm 25 years old"
```

**Key Point:** `this` refers to the object that **calls** the method.
```javascript
let user = {
    name: "Bob",
    showName: function() {
        console.log(this.name);
    }
};

user.showName();  // "Bob"

// Assigning method to variable loses context
let show = user.showName;
show();  // undefined (this is now global/window)
```

---

### C. 'this' in Constructor Functions

In constructors, `this` refers to the **new object being created**.
```javascript
function Person(name, age) {
    this.name = name;
    this.age = age;
    this.greet = function() {
        console.log("Hi, I'm " + this.name);
    };
}

let person1 = new Person("Charlie", 30);
person1.greet();  // "Hi, I'm Charlie"
// 'this' refers to person1
```

---

### D. 'this' in Arrow Functions

**Arrow functions don't have their own `this`!** They inherit `this` from the surrounding scope.
```javascript
let user = {
    name: "Alice",
    
    // Regular function - 'this' works
    greet: function() {
        console.log("Hello, " + this.name);
    },
    
    // Arrow function - 'this' is inherited from outer scope
    greetArrow: () => {
        console.log("Hello, " + this.name);  // undefined!
    }
};

user.greet();       // "Hello, Alice" ✅
user.greetArrow();  // "Hello, undefined" ❌
```

**When arrow functions are useful with `this`:**
```javascript
let counter = {
    count: 0,
    
    start: function() {
        // Regular function - 'this' refers to counter
        setInterval(() => {
            // Arrow function - 'this' inherited from start()
            this.count++;
            console.log(this.count);
        }, 1000);
    }
};

// counter.start();  // 1, 2, 3, 4...
```

---

### E. 'this' in Different Scopes
```javascript
let obj = {
    name: "Object",
    
    method1: function() {
        console.log("method1:", this.name);  // "Object"
        
        function inner() {
            console.log("inner:", this.name);  // undefined (global this)
        }
        inner();
    },
    
    method2: function() {
        console.log("method2:", this.name);  // "Object"
        
        let inner = () => {
            console.log("inner arrow:", this.name);  // "Object" (inherited)
        };
        inner();
    }
};

obj.method1();
obj.method2();
```

## 2. Strict Mode and 'this'

**`use strict`** makes JavaScript stricter and safer.

### A. What is Strict Mode?
```javascript
"use strict";

// Now JavaScript is in strict mode
```

**Benefits:**
- Catches common coding mistakes
- Prevents unsafe actions
- Makes `this` behave differently

---

### B. 'this' in Strict Mode
```javascript
// Without strict mode
function showThis() {
    console.log(this);  // Window object
}
showThis();

// With strict mode
"use strict";
function showThisStrict() {
    console.log(this);  // undefined
}
showThisStrict();
```

**In strict mode, `this` is `undefined` in regular functions (not methods).**
```javascript
"use strict";

let person = {
    name: "Alice",
    greet: function() {
        console.log(this.name);  // Still works! "Alice"
    }
};

person.greet();  // Object methods still have 'this'

function standalone() {
    console.log(this);  // undefined in strict mode
}
standalone();
```

## 3. call(), bind(), and apply()

These methods let you **control what `this` refers to**.

### A. call() Method

**`call()`** invokes a function with a specific `this` value.
```javascript
function greet(greeting) {
    console.log(greeting + ", I'm " + this.name);
}

let person1 = {name: "Alice"};
let person2 = {name: "Bob"};

// Call greet with different 'this'
greet.call(person1, "Hello");  // "Hello, I'm Alice"
greet.call(person2, "Hi");     // "Hi, I'm Bob"
```

**Syntax:**
```javascript
function.call(thisArg, arg1, arg2, ...)
```

**Example with multiple arguments:**
```javascript
function introduce(age, city) {
    console.log(`I'm ${this.name}, ${age} years old from ${city}`);
}

let user = {name: "Charlie"};
introduce.call(user, 30, "New York");
// "I'm Charlie, 30 years old from New York"
```

---

### B. apply() Method

**`apply()`** is like `call()` but takes arguments as an **array**.
```javascript
function introduce(age, city) {
    console.log(`I'm ${this.name}, ${age} years old from ${city}`);
}

let user = {name: "David"};

// apply with array of arguments
introduce.apply(user, [25, "London"]);
// "I'm David, 25 years old from London"
```

**Syntax:**
```javascript
function.apply(thisArg, [arg1, arg2, ...])
```

**call() vs apply():**
```javascript
let person = {name: "Alice"};

function greet(greeting, punctuation) {
    console.log(greeting + ", " + this.name + punctuation);
}

// call - arguments listed separately
greet.call(person, "Hello", "!");

// apply - arguments in array
greet.apply(person, ["Hello", "!"]);

// Both output: "Hello, Alice!"
```

---

### C. bind() Method

**`bind()`** creates a **new function** with `this` permanently bound.
```javascript
let person = {
    name: "Alice",
    greet: function() {
        console.log("Hello, " + this.name);
    }
};

let greetFunction = person.greet;
greetFunction();  // undefined (lost context)

// Bind 'this' to person
let boundGreet = person.greet.bind(person);
boundGreet();  // "Hello, Alice" ✅
```

**Syntax:**
```javascript
let boundFunction = function.bind(thisArg, arg1, arg2, ...)
```

**Example with arguments:**
```javascript
function multiply(a, b) {
    return a * b;
}

// Bind first argument
let double = multiply.bind(null, 2);

console.log(double(5));   // 10 (2 * 5)
console.log(double(10));  // 20 (2 * 10)
```

**Practical use case:**
```javascript
let user = {
    name: "Bob",
    greet: function() {
        console.log("Hello, " + this.name);
    }
};

// Pass method as callback
setTimeout(user.greet, 1000);  // "Hello, undefined" ❌

// Bind to preserve context
setTimeout(user.greet.bind(user), 1000);  // "Hello, Bob" ✅
```

---

### D. Comparison: call, apply, bind

| Method | Invokes Immediately | Arguments Format | Returns |
|--------|-------------------|------------------|---------|
| `call()` | ✅ Yes | Individual | Result |
| `apply()` | ✅ Yes | Array | Result |
| `bind()` | ❌ No | Individual | New function |
```javascript
let person = {name: "Alice"};

function greet(greeting) {
    return greeting + ", " + this.name;
}

// call - executes now
console.log(greet.call(person, "Hello"));  // "Hello, Alice"

// apply - executes now
console.log(greet.apply(person, ["Hi"]));  // "Hi, Alice"

// bind - returns new function
let boundGreet = greet.bind(person, "Hey");
console.log(boundGreet());  // "Hey, Alice"
```

## 4. Classes - Constructor and Methods

Modern JavaScript uses **classes** for OOP.

### A. Basic Class Structure
```javascript
class Person {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }
    
    greet() {
        console.log(`Hello, I'm ${this.name}`);
    }
    
    getInfo() {
        return `${this.name} is ${this.age} years old`;
    }
}

let person1 = new Person("Alice", 25);
person1.greet();  // "Hello, I'm Alice"
console.log(person1.getInfo());  // "Alice is 25 years old"
```

---

### B. Constructor Method

The **`constructor`** is called automatically when creating a new instance.
```javascript
class Car {
    constructor(brand, model, year) {
        console.log("Creating new car...");
        this.brand = brand;
        this.model = model;
        this.year = year;
    }
    
    getInfo() {
        return `${this.year} ${this.brand} ${this.model}`;
    }
}

let car1 = new Car("Toyota", "Camry", 2022);
// "Creating new car..."
console.log(car1.getInfo());  // "2022 Toyota Camry"
```

## 5. Private and Public Properties

Use **`#`** to create **private** properties (ES2022 feature).

### A. Public Properties (Default)
```javascript
class BankAccount {
    constructor(owner, balance) {
        this.owner = owner;      // Public
        this.balance = balance;  // Public
    }
    
    getBalance() {
        return this.balance;
    }
}

let account = new BankAccount("Alice", 1000);
console.log(account.owner);    // "Alice" - accessible
console.log(account.balance);  // 1000 - accessible
```

---

### B. Private Properties with #
```javascript
class BankAccount {
    #balance;  // Private property
    
    constructor(owner, balance) {
        this.owner = owner;       // Public
        this.#balance = balance;  // Private
    }
    
    deposit(amount) {
        this.#balance += amount;
    }
    
    getBalance() {
        return this.#balance;  // Can access inside class
    }
}

let account = new BankAccount("Bob", 1000);
console.log(account.owner);       // "Bob" ✅
console.log(account.getBalance()); // 1000 ✅
// console.log(account.#balance);  // ❌ ERROR! Private field
```

**Why use private?**
- **Encapsulation**: Hide internal implementation
- **Safety**: Prevent accidental modification
- **Control**: Force users to use methods

---

### C. Private Methods
```javascript
class User {
    #password;
    
    constructor(username, password) {
        this.username = username;
        this.#password = password;
    }
    
    // Private method
    #hashPassword(password) {
        return "hashed_" + password;
    }
    
    // Public method
    changePassword(oldPass, newPass) {
        if (this.#password === oldPass) {
            this.#password = this.#hashPassword(newPass);
            return "Password changed";
        }
        return "Wrong password";
    }
}

let user = new User("alice", "secret123");
console.log(user.changePassword("secret123", "newpass"));  // ✅
// user.#hashPassword();  // ❌ ERROR! Private method
```

---

### D. Public vs Private Example
```javascript
class Counter {
    #count = 0;  // Private
    name;        // Public
    
    constructor(name) {
        this.name = name;
    }
    
    increment() {
        this.#count++;
    }
    
    getCount() {
        return this.#count;
    }
    
    // Trying to directly modify #count from outside will fail
}

let counter = new Counter("MyCounter");
counter.increment();
counter.increment();
console.log(counter.getCount());  // 2
console.log(counter.name);        // "MyCounter"
// console.log(counter.#count);   // ❌ ERROR!
```

## 6. Static Methods and Properties

**`static`** methods/properties belong to the **class itself**, not instances.

### A. Static Methods
```javascript
class MathHelper {
    static add(a, b) {
        return a + b;
    }
    
    static multiply(a, b) {
        return a * b;
    }
}

// Call on class, not instance
console.log(MathHelper.add(5, 3));       // 8
console.log(MathHelper.multiply(4, 5));  // 20

// Can't call on instance
let helper = new MathHelper();
// helper.add(5, 3);  // ❌ ERROR!
```

---

### B. Static Properties
```javascript
class User {
    static userCount = 0;  // Static property
    
    constructor(name) {
        this.name = name;
        User.userCount++;  // Increment on class
    }
    
    static getUserCount() {
        return User.userCount;
    }
}

let user1 = new User("Alice");
let user2 = new User("Bob");
let user3 = new User("Charlie");

console.log(User.getUserCount());  // 3
console.log(User.userCount);       // 3
```

---

### C. Practical Use Cases for Static
```javascript
class Validator {
    static isEmail(email) {
        return email.includes("@");
    }
    
    static isStrongPassword(password) {
        return password.length >= 8;
    }
    
    static isValidAge(age) {
        return age >= 0 && age <= 150;
    }
}

// Use without creating instance
console.log(Validator.isEmail("test@example.com"));  // true
console.log(Validator.isStrongPassword("abc"));      // false
console.log(Validator.isValidAge(25));               // true
```

**When to use static:**
- Utility functions that don't need instance data
- Factory methods
- Constants
- Counters across all instances

## 7. Inheritance with extends

**`extends`** creates a class that inherits from another class.

### A. Basic Inheritance
```javascript
// Parent class
class Animal {
    constructor(name) {
        this.name = name;
    }
    
    eat() {
        console.log(this.name + " is eating");
    }
    
    sleep() {
        console.log(this.name + " is sleeping");
    }
}

// Child class
class Dog extends Animal {
    bark() {
        console.log(this.name + " says Woof!");
    }
}

let dog = new Dog("Max");
dog.eat();    // "Max is eating" (inherited)
dog.sleep();  // "Max is sleeping" (inherited)
dog.bark();   // "Max says Woof!" (own method)
```

---

### B. Using super()

Use **`super()`** to call parent constructor.
```javascript
class Animal {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }
    
    getInfo() {
        return `${this.name} is ${this.age} years old`;
    }
}

class Dog extends Animal {
    constructor(name, age, breed) {
        super(name, age);  // Call parent constructor
        this.breed = breed;
    }
    
    getFullInfo() {
        return `${this.getInfo()} and is a ${this.breed}`;
    }
}

let dog = new Dog("Max", 3, "Labrador");
console.log(dog.getInfo());      // "Max is 3 years old"
console.log(dog.getFullInfo());  // "Max is 3 years old and is a Labrador"
```

**Important:** Must call `super()` before using `this` in child constructor!
```javascript
class Child extends Parent {
    constructor(value) {
        // this.value = value;  // ❌ ERROR! Can't use 'this' before super()
        super();  // ✅ Call parent first
        this.value = value;  // ✅ Now okay
    }
}
```

---

### C. Method Overriding

Child can **override** parent methods.
```javascript
class Animal {
    constructor(name) {
        this.name = name;
    }
    
    makeSound() {
        console.log(this.name + " makes a sound");
    }
}

class Dog extends Animal {
    makeSound() {
        console.log(this.name + " barks!");
    }
}

class Cat extends Animal {
    makeSound() {
        console.log(this.name + " meows!");
    }
}

let dog = new Dog("Max");
let cat = new Cat("Whiskers");

dog.makeSound();  // "Max barks!"
cat.makeSound();  // "Whiskers meows!"
```

---

### D. Calling Parent Method with super
```javascript
class Person {
    constructor(name) {
        this.name = name;
    }
    
    introduce() {
        return `I'm ${this.name}`;
    }
}

class Student extends Person {
    constructor(name, grade) {
        super(name);
        this.grade = grade;
    }
    
    introduce() {
        return super.introduce() + ` and I'm in grade ${this.grade}`;
    }
}

let student = new Student("Alice", 10);
console.log(student.introduce());
// "I'm Alice and I'm in grade 10"
```

### E. Multi-Level Inheritance
```javascript
class Vehicle {
    constructor(type) {
        this.type = type;
    }
    
    move() {
        console.log(this.type + " is moving");
    }
}

class Car extends Vehicle {

        super("Car");
        this.brand = brand;
    }

        console.log("Charging " + this.brand + " battery");
    }
}

let tesla = new ElectricCar("Tesla", "100kWh");
tesla.move();    // "Car is moving" (from Vehicle)
tesla.honk();    // "Tesla goes beep!" (from Car)
tesla.charge();  // "Charging Tesla battery" (own method)
```

### F. Practical Example: User System
```javascript
class User {
    constructor(username, email) {
        this.username = username;
        this.email = email;
        this.createdAt = new Date();
    }
    
    getInfo() {
        return `${this.username} (${this.email})`;
    }
}

class Admin extends User {
    constructor(username, email, permissions) {
        super(username, email);
        this.permissions = permissions;
        this.isAdmin = true;
    }
    
    addPermission(permission) {
        this.permissions.push(permission);
    }
    
    getInfo() {
        return super.getInfo() + " [ADMIN]";
    }
}

class Moderator extends User {
    constructor(username, email, department) {
        super(username, email);
        this.department = department;
        this.isModerator = true;
    }
    
    getInfo() {
        return super.getInfo() + ` [MOD: ${this.department}]`;
    }
}

let admin = new Admin("alice", "alice@example.com", ["delete", "ban"]);
let mod = new Moderator("bob", "bob@example.com", "Support");

console.log(admin.getInfo());  // "alice (alice@example.com) [ADMIN]"
console.log(mod.getInfo());    // "bob (bob@example.com) [MOD: Support]"
```

## 💡 Key Takeaways

### ✅ 'this' Keyword
- In objects: refers to the object
- In constructors: refers to new instance
- In arrow functions: inherited from outer scope
- In global/regular functions: window (or undefined in strict mode)

### ✅ Strict Mode
- `"use strict"` at top of file/function
- Makes `this` undefined in regular functions
- Catches common mistakes
- Recommended for all code

### ✅ call, apply, bind
- **call**: Invoke with specific `this`, args listed
- **apply**: Invoke with specific `this`, args in array
- **bind**: Create new function with bound `this`

### ✅ Classes
- Modern OOP syntax
- `constructor` runs on `new`
- Methods defined without `function` keyword

### ✅ Private Properties (#)
- Use `#` for private fields/methods
- Not accessible outside class
- Provides encapsulation

### ✅ Static
- `static` belongs to class, not instances
- Call on class itself: `ClassName.method()`
- Useful for utilities, factories, counters

### ✅ Inheritance (extends)
- `class Child extends Parent`
- `super()` calls parent constructor
- `super.method()` calls parent method
- Child can override parent methods

## 📊 Comparison Tables

### call vs apply vs bind

| Feature | call | apply | bind |
|---------|------|-------|------|
| Executes immediately | ✅ | ✅ | ❌ |
| Arguments | Individual | Array | Individual |
| Returns | Result | Result | New function |

### Public vs Private

| Type | Syntax | Accessible Outside | Use Case |
|------|--------|-------------------|----------|
| Public | `this.prop` | ✅ Yes | API, user-facing data |
| Private | `#prop` | ❌ No | Internal implementation |

### Instance vs Static

| Type | Belongs to | Access via | Use Case |
|------|-----------|-----------|----------|
| Instance | Each object | `instance.method()` | Object-specific behavior |
| Static | Class itself | `Class.method()` | Utilities, factories |
