## 1. Comparison Operators (The Decision Makers)

Comparison operators always return a **Boolean** (`true` or `false`). They allow our code to ask questions.

### A. The Equality Battle: `==` vs `===`

This is one of the most important concepts in JS.

**`==` (Loose Equality):** Only compares the **value**. It performs "Type Coercion" (it forces the types to match).
```javascript
5 == "5"  // true (JS converts the string to a number)
```

**`===` (Strict Equality):** Compares both **value AND data type**.
```javascript
5 === "5"  // false (Number vs. String)
```
> **Pro Tip:** Always use `===` to prevent unexpected bugs.

### B. Inequality: `!=` vs `!==`

- **`!=` (Loose Inequality):** Returns `true` if values are different, ignoring type.
- **`!==` (Strict Inequality):** Returns `true` if either the value OR the type is different.
```javascript
5 != "5"   // false (values are same after coercion)
5 !== "5"  // true (types are different)
```

### C. Relational Operators

Used primarily for numerical comparisons:
```javascript
>   // Greater than
<   // Less than
>=  // Greater or equal
<=  // Less or equal
```

**Example:**
```javascript
10 > 5   // true
10 <= 10 // true
```

## 2. The Math Object (Built-in Intelligence)

The `Math` object is a built-in library that handles mathematical operations. Unlike other objects, you don't "create" it; it's just there.

### Essential Methods:

#### `Math.floor(x)` - Rounds **down** to the nearest integer
Removes everything after the decimal.
```javascript
Math.floor(3.9)  // 3
Math.floor(5.1)  // 5
```

#### `Math.ceil(x)` - Rounds **up** to the nearest integer
```javascript
Math.ceil(3.1)  // 4
Math.ceil(5.9)  // 6
```

#### `Math.round(x)` - Standard rounding
`.5` and above goes up, below `.5` goes down.
```javascript
Math.round(3.5)  // 4
Math.round(3.4)  // 3
```

#### `Math.random()` - Generates a random number
Returns a number between `0` (inclusive) and `1` (exclusive).
```javascript
Math.random()  // 0.6372819...

// To get a number between 1-10:
Math.floor(Math.random() * 10) + 1
```

#### Other Useful Math Methods:
```javascript
Math.abs(-5)        // 5 (absolute value)
Math.max(10, 5, 8)  // 10 (maximum value)
Math.min(10, 5, 8)  // 5 (minimum value)
Math.pow(2, 3)      // 8 (2 to the power of 3)
Math.sqrt(16)       // 4 (square root)
```

## 3. String Methods (Quick Recap)

Strings are not just text; they have "methods" (built-in functions) that can manipulate them.
```javascript
let text = "JavaScript";

text.length              // 10 (property, not a method)
text.toUpperCase()       // "JAVASCRIPT"
text.toLowerCase()       // "javascript"
text.includes("Script")  // true
text.charAt(0)           // "J"
text.substring(0, 4)     // "Java"
```

> **Note:** String methods don't modify the original string; they return a new one.

## 4. Functions (The Reusable Machines)

A function is a block of code designed to perform a particular task. You define it once and call it whenever you need.

### Structure of a Function:
```javascript
function nameOfFunction(parameter1, parameter2) {
    // Code to be executed
    return result; // The output
}
```

### Example 1: Function without parameters
```javascript
function greet() {
    console.log("Hello, World!");
}

greet(); // Call the function
```

### Example 2: Function with parameters
```javascript
function greet(name) {
    console.log("Hello, " + name + "!");
}

greet("Ahmet"); // "Hello, Ahmet!"
greet("Ayşe");  // "Hello, Ayşe!"
```

### Example 3: Function with return
```javascript
function add(a, b) {
    return a + b;
}

let result = add(5, 3);  // result = 8
console.log(add(10, 20)); // 30
```

### Parameters vs Arguments:
- **Parameters:** Variable names in the function definition (`a`, `b`)
- **Arguments:** Actual values passed when calling (`5`, `3`)
```javascript
function multiply(x, y) {  // x and y are parameters
    return x * y;
}

multiply(4, 5);  // 4 and 5 are arguments
```

## 💡 Key Takeaways

### ✅ Strict Equality (`===`)
Always use `===` over `==`. It checks both value and type, preventing bugs caused by automatic type conversion (coercion).

### ✅ Comparison Logic
Every comparison operation (`==`, `===`, `!=`, `!==`, `>`, `<`, `>=`, `<=`) results in a Boolean (`true` or `false`).

### ✅ Math Rounding
- **`Math.floor()`:** Always rounds down (towards the floor)
- **`Math.ceil()`:** Always rounds up (towards the ceiling)
- **`Math.round()`:** Rounds to the nearest whole number

### ✅ Randomness
`Math.random()` generates a decimal between 0 and 1. Combined with `Math.floor()`, it is used to create random integers.

### ✅ Function Definitions
Functions allow you to write code once and reuse it. A function without a `return` statement will return `undefined` by default.

### ✅ Parameters vs. Arguments
- **Parameters** are the variable names in the function definition
- **Arguments** are the real values you pass when calling the function

### ✅ The `return` Keyword
It is the "output" of the function. It sends a value back and immediately stops the function's execution.
