## 🧱 1. Foundations: Variables & Data Types

JavaScript starts with **data**.

### 🔹 Primitive Types (Value Types)

Passed **by value** (copied in memory).

* `String`
* `Number`
* `Boolean`
* `Null`
* `Undefined`
* `Symbol`
* `BigInt`

```js
let a = 10;
let b = a;
b = 20;
// a is still 10 → value copy
```

### 🔹 Reference Types (Object Types)

Passed **by reference** (same memory address).

* `Object`
* `Array`
* `Function`

```js
let arr1 = [1,2,3];
let arr2 = arr1;
arr2.push(4);
// arr1 === [1,2,3,4]
```

### 🔹 Variable Declarations

* `let` → block-scoped, reassignable
* `const` → block-scoped, reference is fixed
* `var` → function-scoped (legacy, **avoid**)

## 🌱 4A. Constructor Functions (The Roots of OOP)

```js
function User(name, role) {
  this.name = name;
  this.role = role;
}

User.prototype.sayHi = function() {
  return `Hi ${this.name}`;
};

const u1 = new User('Gokhan', 'Developer');
```

### 🔹 What does `new` do?

1. Creates an empty object
2. Binds `this` to that object
3. Links the prototype
4. Returns the object

---

## 🚀 4B. ES6 Classes (Modern OOP)

> **Syntactic sugar** — under the hood, still prototypes.

```js
class User {
  constructor(name, role) {
    this.name = name;
    this.role = role;
  }

  sayHi() {
    return `Hi ${this.name}`;
  }
}
```

### 🔹 `constructor()`

* Runs **once per instance**

### 🔹 Class vs Function

* More readable
* More maintainable
* Industry standard

## ⚡ 5. Advanced OOP Concepts

This is where **junior → mid → senior** separation begins.

---

## 🧠 I. `this` Context & Binding

Context loss example:

```js
const greet = user.sayHi;
greet(); // ❌ this is undefined
```

### 🔹 Fixing Context

* `.call(thisArg, args)`
* `.apply(thisArg, [])`
* `.bind(thisArg)`

```js
const bound = user.sayHi.bind(user);
bound(); // ✅
```

---

## 🔐 II. Encapsulation (Private Fields)

True OOP means **protecting internal state**.

```js
class BankAccount {
  #balance = 0;

  deposit(amount) {
    this.#balance += amount;
  }

  getBalance() {
    return this.#balance;
  }
}
```

* `#balance` is inaccessible from outside
* Only controlled access is exposed

---

## 🧬 III. Inheritance & Polymorphism

### 🔹 Inheritance

```js
class Animal {
  speak() {
    return 'sound';
  }
}

class Dog extends Animal {
  speak() {
    return 'woof';
  }
}
```

* `extends` → inheritance
* `super()` → parent constructor / method

### 🔹 Polymorphism

Same method name → different behavior

```js
const animals = [new Animal(), new Dog()];
animals.forEach(a => console.log(a.speak()));
```
